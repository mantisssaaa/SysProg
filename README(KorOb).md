CLOSED FRONTLINE — простая пошаговая игра на Go с ASCII-графикой.

Ты сражаешься сражаешься с врагом или своим (пока ещё) другом. У каждого есть здоровье, энергия и зелья. Игроки ходят по очереди.

Есть три режима: одиночный против бота (враг становится сильнее с каждым уровнем), игра вдвоём на одном компьютере и онлайн по локальной сети через прямое подключение по IP.

В бою можно атаковать, сделать сильный удар за энергию, выпить зелье или уйти в защиту (она уменьшает урон и даёт энергии восстановиться). Побеждает тот, кто обнулит здоровье противника.

Запуск(в терминале в директории с игрой): go run .
